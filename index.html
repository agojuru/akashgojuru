RISC-V 5-Stage Pipelined Processor

we built a RISC-V processor step by step and finished with a complete 5-stage pipelined CPU (IF, ID, EX, MEM, WB). We added pipeline registers, forwarding, hazard detection, stalls, and branch logic so instructions run correctly each cycle. This was a team project with two members. My partner handled most of the RTL coding, and I supported by reviewing the design, finding bugs, and suggesting fixes for control and data hazards. I also wrote most of the design documents, including datapath and control signal explanations. We tested the processor using RARS assembly (.s) files and used QuestaSim waveforms to verify timing and debug pipeline behavior. We also ran many instruction sequences to confirm correct register updates, memory access, and branch/jump results. Finally, we improved modularity by organizing the ALU, register file, control unit, and memory interface into reusable VHDL components.

CyBot Roomba Project

In CPRE 2880, I worked on a semester-long embedded systems lab using the CyBot robot. Each week, we implemented new features in C, which helped me improve my programming skills and understand how microcontrollers interact with real hardware. I learned how to use timers, interrupts, UART communication, and both analog and digital peripherals, and I practiced debugging with real sensor data. For the final project, my team of three programmed the CyBot to navigate an obstacle course like a moon rover. The biggest challenge was that the operator could not see the robot or the course, so we had to rely completely on sensors such as bump sensors and IR/PING distance scanners. We designed and tested a solution that could detect obstacles, avoid holes and boundary lines, and safely move through the course. This project strengthened my teamwork, problem solving, and embedded system design skills.

Weighless Neural Network

I worked on a Weightless Neural Network (WNN) project based on the WiSARD model, which performs classification using RAM-like memory instead of traditional weighted multiplications. The idea is to convert each input sample into a binary vector and split it into small groups of bits. Each group is used as an address to a memory table, and the model learns by incrementing counts in those memory locations during training. For inference, the same addresses are generated and the counts are summed to produce a score for each class. I implemented the hashing/addressing approach H3-style constants to distribute bits across memory and reduce collisions. I verified correctness using test inputs and measured classification accuracy while exploring tradeoffs between memory size, number of discriminators, and performance. This project helped me understand lightweight ML hardware concepts and why WNNs can be efficient for edge devices.

Senior Design

Our senior design project is to build an open-source Bluetooth Low Energy (BLE) microcontroller. My team is mainly working on the digital Link Layer controller, which is the part that handles advertising, scanning, making a connection, and sending data. We are working on this project for two semesters with the ChipForge team and our faculty advisor.

My role is on the digital Link Layer design. I read the BLE Link Layer spec and turned it into clear hardware tasks. I made summary sheets for the main PDUs used in advertising, scanning, and connecting, and I noted important header bits like TxAdd, RxAdd, ChSel, and Length. I also studied Channel Selection Algorithm #1 (CSA#1) to understand how BLE hops channels during a connection. Next, I will start helping with PDU decode and PDU generation, and connect them to the state machine and test cases for the MVP flow advertising → scanning → connection.
